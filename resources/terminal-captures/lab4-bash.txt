== Lab 4 Part 2: Bash commands ==
$ echo hello > f; cat < f
hello
$ ls | grep READ
README
$ (echo a; echo b) | wc
      2       2       4
$ echo one; echo two
one
two
$ echo bg &
bg
$ ls *
f
README
$ echo $HOME
/home/user
$ echo "a b"
a b
$ mkdir d; cd d; ls ..
d
f
README
Up arrow, Tab, and Ctrl+R require an interactive terminal; see note in report.
