# Combined Lab 5 & 6 notes

This directory combines the filesystem-related work from Lab 5 and Lab 6.

The purpose is to keep both exercises together in a single folder, matching the idea of a single combined assignment rather than splitting the filesystem work across two directories.

## Included topics

- Linux filesystem basics
- file types and inode behavior
- hard links and symbolic links
- permissions and special bits
- `/proc`, `df`, `du`, and `lsblk`
- xv6 file system internals
- `mystat` behavior
- recursive `find` behavior

## Placement

The work for Lab 5 is stored in the same folder as the Lab 6 xv6 filesystem tasks, so the full filesystem assignment can be handled as one unit.
